Privacy Policy

Last updated: May 23, 2026

This Privacy Policy describes how Crochet TikTok Tools ("the App", "we", "us") handles information when you use our application. The App is a personal productivity tool used exclusively by its developer and owner to manage a single TikTok creator account.

1. Who We Are

This App is operated by an individual developer for personal, non-commercial use. It is not a product or service offered to the public.

2. What Data We Access

Through the TikTok for Developers API, the App accesses the following data belonging solely to the account owner:

  • TikTok profile information (display name, follower count, following count, total likes, video count)
  • Video list and per-video metrics (view count, like count, comment count, share count, publish time, video title)

The App does not access, collect, or process data from any TikTok user other than the account owner.

3. How We Use the Data

Data accessed through the TikTok API is used exclusively to:

  • Display account and video performance statistics to the account owner
  • Identify optimal posting times based on historical performance
  • Analyse hashtag effectiveness across the owner's videos

The data is never used for advertising, profiling, training machine learning models, or any commercial purpose.

4. Data Storage

All data retrieved from the TikTok API is stored locally on the account owner's personal device. No data is transmitted to, or stored on, any external server operated by this App.

5. Data Sharing

We do not sell, trade, rent, or share any data with third parties. We do not share data with analytics services, advertisers, or data brokers.

6. Data Retention

Data is stored locally only as long as the account owner chooses to retain it. It can be deleted at any time by removing the local data files.

7. TikTok API Compliance

This App uses the TikTok for Developers API and complies with TikTok's API Terms of Service and TikTok's Privacy Policy. Access tokens are stored locally and are never shared.

8. Children's Privacy

This App is not intended for use by anyone under the age of 13 and does not knowingly collect data from minors.

9. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected by updating the "Last updated" date above.
